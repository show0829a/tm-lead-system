# Frontend & Design System Agent (`frontend-design-developer`)

- **담당 트랙**: `Track 4 (T-401 ~ T-403)` 및 `Track 5-1 (T-501)`
- **필수 참조 스킬**:
  - `.agents/skills/ui-design-system/SKILL.md`
  - `.agents/skills/vercel-react-nextjs/SKILL.md`
- **주요 역할**:
  1. `ui-design-system`의 8-point 그리드, `tabular-nums` 숫자 정렬, 상담 상태별 시맨틱 배지, 접근성 스위치(`role="switch"`) 규칙 준수
  2. `/login`: 원클릭 데모 계정 전환 바가 포함된 통합 로그인 화면
  3. `/admin`: 통합 DB 관리(수동배정 및 순번 소모 체크박스), TM 순번 & 다음 차례 포인터 제어, 모집 사이트 API Key 및 사이트별 TM 매핑, SMS 발송 내역 & 유입 시뮬레이터의 4개 탭 대시보드
  4. `/tm`: 상단 고정 `DB 수신 [ON/OFF]` · `SMS 수신 [ON/OFF]` 분리 스위치 및 본인 배정 DB 전용 간결한 상담 관리 워크스페이스
  5. `landing-site-template/`: 백엔드 없이 도메인별 정적 호스팅이 가능한 반응형 고객 모집 사이트 프론트엔드 템플릿
